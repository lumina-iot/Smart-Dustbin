# 🗑️ Smart Dustbin Using Arduino

## 📌 Project Description
The **Smart Dustbin** is an Arduino-based project designed to make waste disposal more convenient and hygienic. The system can detect a person or an object near the dustbin and automatically open the lid, reducing the need for physical contact.

The project is designed for circuit simulation using Tinkercad Circuits. It demonstrates how sensors, an Arduino microcontroller, and automation can be combined to create a simple smart waste management solution.

## 🎯 Objectives
- Reduce physical contact with the dustbin.
- Automate the opening and closing of the lid.
- Understand Arduino programming and sensor interfacing.
- Explore automation through virtual circuit simulation.
- Promote hygienic and convenient waste disposal.

## ⚙️ Technologies Used
- **Simulation Platform:** Tinkercad Circuits
- **Microcontroller:** Arduino Uno
- **Programming Language:** Arduino C/C++
- **Components:** Sensors, servo motor, and other components used in the circuit.

## 🔄 How It Works
1. The sensor detects an object near the dustbin.
2. The sensor sends a signal to the Arduino Uno.
3. The Arduino processes the sensor readings.
4. The servo motor opens the lid when the detection condition is met.
5. The lid closes automatically after the object moves away or after the programmed delay.
